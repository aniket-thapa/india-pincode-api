Quick start

      
Copy any snippet and start fetching postal data.


      

        
        
        
      


      

        
const BASE = 'https://aniket-thapa.github.io/india-pincode-api';

        const res = await fetch(`${BASE}/pincodes/110001.json`);
        const data = await res.json();

        console.log(data.state);    // "DELHI"
        console.log(data.district); // "NEW DELHI"
        console.log(data.offices);  // [{officeName, officeType, ...}]

      


      

        
import requests

BASE = "https://aniket-thapa.github.io/india-pincode-api"

res = requests.get(f"{BASE}/pincodes/110001.json")
data = res.json()

print(data["state"])    # DELHI
print(data["district"]) # NEW DELHI

Endpoints

      
Four endpoints. Predictable URLs. Click to expand.


      

        
        

          

            GET
            /states.json
            List all states & UTs
            ▼
          

          

            
Returns every state and union territory with district count and total post office count.
            

            
Response

            
[
  {
    "name": "ANDHRA PRADESH",
    "slug": "andhra-pradesh",
    "districtCount": 26,
    "officeCount": 10681
  }
  // ... 35 more
]

          

        


        
        

          

            GET
            /states/{state-slug}.json
            State details & districts
            ▼
          

          

            
Returns state metadata and all districts with their office counts.

            

              💡
              
Example: /states/maharashtra.json,
                /states/uttar-pradesh.json
              

            

            
Response

            
{
  "name": "RAJASTHAN",
  "slug": "rajasthan",
  "districtCount": 33,
  "districts": [
    { "name": "JODHPUR", "slug": "jodhpur", "officeCount": 446 }
    // ... 32 more
  ]
}

          

        


        
        

          

            GET
            /districts/{state-slug}/{district-slug}.json
            All offices in a district
            ▼
          

          

            
Returns every post office in a district with name, type, delivery status, circle, region,
              division, pincode, and GPS coordinates.

            

              💡
              
Example: /districts/rajasthan/jodhpur.json,
                /districts/maharashtra/pune.json
              

            

            
Response

            
{
  "state": "RAJASTHAN",
  "district": "JODHPUR",
  "offices": [
    {
      "officeName": "Jodhpur HO",
      "officeType": "HO",
      "deliveryStatus": "Delivery",
      "pincode": "342001",
      "latitude": 26.2889,
      "longitude": 73.0243
    }
    // ... 445 more
  ]
}

          

        


        
        

          

            GET
            /pincodes/{6-digit-pincode}.json
            Pincode lookup
            ▼
          

          

            
Returns all post offices under a specific pincode with state and district context. The
              pincode field is omitted since it's encoded in the URL.
            

            

              ⚠️
              
A single pincode can map to multiple offices. Always iterate offices[] and null-check
                latitude/longitude.
              

            

            
Response

            
{
  "state": "DELHI",
  "district": "NEW DELHI",
  "offices": [
    {
      "officeName": "New Delhi GPO",
      "officeType": "HO",
      "deliveryStatus": "Delivery",
      "latitude": 28.626806,
      "longitude": 77.20663
    }
  ]
}

Field reference

      
Office objects share a consistent schema across all endpoints.


      

        

          
            

              Field
              Type
              Description
            

          
          
            

              officeName
              string
              Name of the post office
            

            

              officeType
              string
              HO (Head), SO (Sub), BO (Branch),
                PO (Post Office)
              
            

            

              deliveryStatus
              string
              "Delivery" or "Non Delivery"
            

            

              circleName
              string
              Postal circle (e.g. "Rajasthan Circle")
            

            

              regionName
              string
              Postal region within the circle
            

            

              divisionName
              string
              Postal division within the region
            

            

              latitude
              number | null
              WGS-84 latitude. null when unavailable.
            

            

              longitude
              number | null
              WGS-84 longitude. null when unavailable.
            

            

              pincode
              string
              6-digit pincode. Only in district endpoint responses.
            

          
        

      


      

        
Slug convention

        

          Names are lowercased, non-alphanumeric characters replaced with hyphens, leading/trailing hyphens trimmed.
        

        

          

            
              

                Official name
                Slug
              

            
            
              

                UTTAR PRADESH
                uttar-pradesh
              

              

                JAMMU AND KASHMIR
                jammu-and-kashmir
              

              

                KUMURAM BHEEM ASIFABAD
                kumuram-bheem-asifabad
